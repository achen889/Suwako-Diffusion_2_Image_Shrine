# Waifu Diffusion 1.5 Beta 2 prompt notes

Status: not tested yet.

Do not assume Animagine's tokenizer limit or tag behavior applies to this model.
When testing, record:

- Final composed positive and negative prompt token counts and the active tokenizer
  limits.
- Whether enhanced-mode additions help or consume useful context.
- How it responds to Danbooru-style tags versus short natural-language phrases.
- Annette hair, eye, and skin consistency; pose accuracy; anatomy; and composition.
- Resolution, steps, guidance, seed, elapsed time, and output run path.

Use the same short prompt and seed as an initial comparison where the model supports
them, then make model-specific changes only after reviewing the saved outputs.
